# Reporting a problem

Email adamalshoomary@gmail.com, or open an issue for anything that is not
sensitive.

**Never attach a `.env` file or an audio recording to an issue.** The `.env`
holds third party API keys, and a recording carries an identifiable person's
voice. Both are public the moment they land in a public repository, and a later
deletion does not remove them from its history.

This is a research artifact rather than a deployed service, so there is nothing
running to attack. What can go wrong is a person publishing their own
credentials or somebody else's voice by accident.
